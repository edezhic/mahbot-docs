The XML parts in this directory are captured output, not hand-written source: they are the parts a
created presentation does not vary in, taken verbatim from what pptxgenjs 4.0.1 writes — the pinned
presentation library the reference kit runs on. The parts this crate writes itself are its own code;
these are the library's output, reproduced so that a produced deck is the reference's deck element
for element.
